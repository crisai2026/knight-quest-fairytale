# Chapter 1 — A different challenge in every scene

Right now the 10 scenes of the Sunny Forest are all generated by the same
formula: same look, same furry monsters, just slightly longer each time.
This plan gives each scene its own small gameplay twist so moving from one
scene to the next always feels different. The visuals stay the sunny forest.

## The 10 scenes

1. **Forest Path** — Gentle warmup. A couple of furry monsters, wide
   platforms, a food chest. Teaches walk / jump / sword.
2. **Mossy Clearing** — Jumping scene. Almost no monsters; instead many
   platforms in a row with gaps, food placed up high as a reward.
3. **Fallen Logs** — Monster gauntlet. Flat ground, few platforms, but many
   furry monsters patrolling in a row. Fight or sprint through.
4. **Bramble Hollow** — Wind scene. Gusts of wind periodically push the
   knight sideways (leaves blow across the screen as a warning). Time your
   jumps between gusts.
5. **Sunlit Glade** — Moving platforms. Two or three platforms slide up and
   down (or side to side); ride them to cross a long gap.
6. **Old Oak Ridge** — Hunger challenge. A longer scene with no food chests
   until the very end — manage sprinting so hunger doesn't run out.
7. **Mushroom Grove** — Bounce mushrooms. Big bouncy mushrooms launch the
   knight high into the air; use them to reach tall platforms and skip
   monsters below.
8. **Thorn Thicket** — Air attack. Winged monsters (already in the game)
   swoop above the path; poke upward or use the bow.
9. **Wolf Den Trail** — Mixed review. A bit of everything from earlier
   scenes: some wind, a moving platform, a bounce mushroom, several
   monsters.
10. **The Furry King's Grove** — Boss fight, unchanged.

Each scene shows its twist in the start card / scene intro text, e.g.
"Watch out for the wind!".

## Technical details

- `SceneDef` in `src/lib/game/levels.ts` gains optional flags:
  `wind?: boolean`, and its `platforms` may carry `move` info; mushrooms
  become a new simple `bounces` list (`{x, y}`) per scene.
- `Platform` in `types.ts` gains optional `axis: "x"|"y"`, `range`, `speed`
  so the engine can oscillate it; the knight standing on one is carried
  along. Collision still uses the existing rect code — the platform's
  x/y just gets updated each frame.
- Wind: a per-scene gust cycle (about 4s calm, 2s blowing) that adds a
  constant push to the player's x-velocity and spawns leaf particles;
  a small sound using the existing WebAudio noise generator.
- Bounce mushroom: drawn as a big red mushroom; landing on it sets a strong
  upward velocity with the existing jump sound (higher pitch).
- `forestScene()` is replaced by 10 hand-written scene definitions built
  from small helpers (`platRow`, `furryPack`, etc.) so each scene's layout
  matches its twist.
- Scene start card (`levelstart`) gains a one-line hint per scene.
- The scene map already exists; no changes there. Other chapters untouched.
- Save format unchanged (`sceneProgress` still a number per chapter).
